# Animal sound credits

The animal cries are recordings from [Wikimedia Commons](https://commons.wikimedia.org/) (some originally published on
Freesound, xeno-canto or PDSounds). They were adapted for this game as described in the last column. Each recording keeps its
original license, which is different from the MIT license of the game's code. The adapted MP3 files are made available under the
same license as their original (for CC BY-SA files: CC BY-SA, so you may reuse them under those terms with attribution).

Machine-readable data (with SHA-256 checksums): [`sources.json`](sources.json). This is also what the in-app credits screen shows.

provenance was doubtful (a cow file cropped from a commercial "Sound Ideas" library track, and a frog file labelled both "own work" and
"recorded in 1934").
