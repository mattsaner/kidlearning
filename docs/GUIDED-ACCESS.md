# Keeping your child in the game: Guided Access on iPad / iPhone

*Version française plus bas · Deutsche Kurzfassung am Ende.*

A web page cannot lock an iPad: the Home swipe, app switching, Safari's address bar and tabs all belong to the system.
Apple's **Guided Access** is the built-in kiosk mode that solves this. It keeps the device in one app until a passcode is entered.
Combine it with running the game as a Home Screen app.

## 1. Add the game to the Home Screen (once)

1. Open the game in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. From now on, always start the game from that icon. It runs full screen, without Safari's address bar or tabs.

If you added the game before, remove the old icon and add it again to get the new icon and full-screen mode.

## 2. Turn on Guided Access (once)

1. **Settings → Accessibility → Guided Access**, switch it **on**.
2. **Passcode Settings → Set Guided Access Passcode.** Choose a code your child does not know. You can also allow Face ID / Touch ID to end a session.
3. Optional: **Time Limit Alerts** (a sound or a spoken warning before a session ends).
4. **Settings → Accessibility → Accessibility Shortcut** → tick **Guided Access**. This is what makes the triple-click work.

## 3. Start a session (every time)

1. Open the game from its Home Screen icon.
2. **Triple-click the Top button** (iPads with Face ID or a Touch ID top button) or the **Home button** (iPads with one). On iPhones with Face ID, triple-click the side button.
3. Tap **Options** (bottom left) and check:
   - **Touch: on** (the game needs it).
   - **Motion: off** is fine. Keyboards, Side Button and Volume Buttons can stay off.
   - **Time Limit:** set how long the session may last if you want the iPad itself to end it. This works together with the game's own play-time limit (hold ⚙️ in the game → *Temps de jeu*).
4. Optional: with your finger, circle any area of the screen you want to disable (touching it then does nothing).
5. Tap **Start** (top right).

While it runs, the Home swipe, the app switcher, notifications and the Safari bars are unavailable, and the device cannot leave the game.

## 4. End the session

Triple-click the same button, enter the passcode (or use Face ID / Touch ID), then tap **End** (top left).

## Tips and troubleshooting

- **Nothing happens on triple-click:** check *Accessibility Shortcut* (step 2.4) and be inside the game app, not on the Home Screen. Click the button three times quickly.
- **The screen locks too soon:** *Settings → Accessibility → Guided Access → Display Auto-Lock* sets how long the screen stays on during a session.
- **Forgot the passcode:** follow Apple's instructions for resetting the Guided Access passcode (see the Apple documentation below) before you start a session for your child.
- **Also good to know:** the game blocks the edge-swipe "back" gesture, pinch-zoom, text selection and long-press menus, and has no web links except in the parent-only credits screen (behind the ⚙️ press-and-hold).
- Menu names can differ slightly between iPadOS versions. See Apple's documentation: *Use Guided Access with iPhone and iPad*.

## Version française

Une page web ne peut pas verrouiller un iPad. L'**Accès guidé** d'Apple garde l'appareil dans une seule app jusqu'à la saisie d'un code.

1. **Ajouter à l'écran d'accueil (une fois) :** ouvrez le jeu dans Safari → **Partager** → **Sur l'écran d'accueil**. Lancez ensuite toujours le jeu depuis cette icône (plein écran, sans barre d'adresse).
2. **Activer l'Accès guidé (une fois) :** *Réglages → Accessibilité → Accès guidé* → activé. *Réglages du code* → définissez un code secret (Face ID / Touch ID possible). *Réglages → Accessibilité → Raccourci d'accessibilité* → cochez **Accès guidé**.
3. **Démarrer :** ouvrez le jeu, **triple-cliquez sur le bouton supérieur** (ou le bouton principal), touchez **Options** (Toucher : activé ; limite de temps possible), puis **Démarrer**. Facultatif : entourez du doigt une zone à désactiver.
4. **Terminer :** triple-clic, saisissez le code (ou Face ID), puis **Fin**.

Astuce : le jeu a aussi son propre minuteur (⚙️ maintenu → *Temps de jeu*) et bloque le retour par balayage du bord, le zoom et la sélection de texte.

## Deutsche Kurzfassung

Eine Webseite kann das iPad nicht sperren. Der **Geführte Zugriff** hält das Gerät in einer App, bis ein Code eingegeben wird.

1. Spiel in Safari öffnen → **Teilen → Zum Home-Bildschirm**; danach immer über dieses Symbol starten.
2. *Einstellungen → Bedienungshilfen → Geführter Zugriff* einschalten, Code festlegen; unter *Kurzbefehl für Bedienungshilfen* „Geführter Zugriff" aktivieren.
3. Spiel öffnen, **dreimal die obere Taste (oder Home-Taste) drücken → Optionen → Starten**.
4. Beenden: dreimal drücken, Code eingeben, **Beenden**.
